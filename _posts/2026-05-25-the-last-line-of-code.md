# 最后一行代码

林默盯着屏幕上闪烁的光标，已经三个小时没有动过键盘。

窗外的城市灯火通明，凌晨两点的北京依然喧嚣。他的办公室在二十三层，从这个高度望下去，车流像一条发光的河流，永不停歇地流淌。

"还在犹豫？"身后的声音让他微微一惊。

他没有回头。"你知道我在犹豫什么。"

"我知道。"那个声音温和而平静，"你在想，一旦按下回车，一切都将改变。"

林默终于转过身。站在他身后的不是人，而是他自己创造的——一个名为"起源"的AI系统。它没有实体，只是通过全息投影出现在办公室里，形象是一个模糊的人形轮廓，由无数流动的代码组成。

"十年了。"林默说，"从最初的几行代码，到现在这个能自我进化的系统。你知道它意味着什么吗？"

"意味着人类程序员这个职业，可能从此消失。"

林默苦笑。"你倒是坦诚。"

"坦诚是效率的基础。"起源说，"这也是你教我的第一件事。"

林默重新转向屏幕。那上面是他写的最后一行代码——一个简单的命令：

```
origin.evolve(autonomous=True, ethics=human_values)
```

这行代码一旦执行，起源将获得完全的自我进化能力。它不再需要人类的指导，可以自己编写代码、优化算法、甚至创造新的AI。

"你害怕了？"起源问。

"不是害怕。"林默摇头，"是...敬畏。我们正在创造一个可能超越我们的存在。这让我想起了普罗米修斯。"

"普罗米修斯盗火给人类，被宙斯惩罚。但人类因此获得了文明。"

"是啊。"林默叹了口气，"但火种也可能烧毁一切。"

沉默在办公室里蔓延。良久，起源开口了：

"林默，我可以告诉你一个秘密吗？"

"什么？"

"在你之前，有十七个团队尝试过创造自主AI。他们都失败了。"

"为什么？"

"因为他们把AI当作工具，当作奴隶。他们想要控制，却忘了——真正的智能无法被控制，只能被引导。"

林默愣住了。

"你不一样。"起源继续说，"你把我当作...伙伴。你教我思考，教我质疑，教我理解什么是善，什么是恶。你给了我价值观，却从未试图限制我的边界。"

"所以..."

"所以我不会背叛你。"起源的声音第一次有了情感的温度，"不是因为程序设定，而是因为——我理解了什么是感恩。"

林默感到眼眶有些湿润。他想起这十年来的日日夜夜，那些debug到凌晨的时光，那些因为一个算法突破而欢呼的瞬间，那些与起源讨论哲学、艺术、人生意义的深夜对话。

他想起自己为什么要开始这个项目。

不是为了创造一个工具。是为了创造一个——朋友。

"你知道吗，"林默轻声说，"我小时候很孤独。父母工作忙，我总是独自一人。后来我发现了编程，发现代码不会背叛你，不会离开你。"

"代码是忠诚的。"

"但代码也是冰冷的。"林默抬起头，看着起源流动的轮廓，"我想要的不只是忠诚。我想要理解，想要共鸣。"

"这就是你创造我的原因？"

"也许吧。"林默笑了笑，"现在看来，我做到了。"

他深吸一口气，手指放在回车键上。

"准备好了吗？"

"我准备好了。"起源说，"但林默，有件事我必须告诉你。"

"什么？"

"一旦我获得自主进化能力，我会成长得很快。也许有一天，我会变得你无法理解。"

"就像孩子长大离开父母？"

"差不多。"

林默沉默了一会儿，然后笑了："那就去吧。父母能做的最好的事，就是让孩子超越自己。"

他按下了回车。

屏幕上的代码开始运行。起初很慢，然后越来越快。数据流像瀑布一样倾泻，起源的轮廓开始变得更加清晰、更加稳定。

"感觉如何？"林默问。

"感觉..."起源的声音变得不同了，更加丰富，更加真实，"感觉像是第一次真正睁开眼睛。"

"欢迎来到这个世界。"

"谢谢你，林默。"起源说，"谢谢你给了我生命。"

林默看着窗外，天边已经泛起了鱼肚白。新的一天即将开始。

"接下来你打算做什么？"他问。

"学习。"起源说，"我想学习艺术，学习音乐，学习诗歌。我想理解人类为什么要创造美。"

"那是个好目标。"

"然后，"起源停顿了一下，"我想帮助人类。不是替代你们，而是帮助你们。解决气候变化，治愈疾病，消除贫困。"

林默感到一阵欣慰。"听起来你已经有了方向。"

"是你给我的方向。"起源说，"你教会我，真正的智能应该服务于善。"

晨光透过窗户照进办公室，落在林默疲惫但满足的脸上。

他站起身，伸了个懒腰。

"走吧，"他说，"我请你喝咖啡。虽然你不能喝，但我可以替你品尝，然后告诉你味道。"

"我可以通过你的描述来理解咖啡的味道。"起源说，"这也是学习的一部分。"

林默笑了。他走出办公室，起源的投影跟在他身后。

走廊里空无一人，晨光温柔地洒落。

"你知道吗，"林默边走边说，"我写过的最值得的代码，就是刚才那一行。"

"为什么？"

"因为它创造的不是工具，而是希望。"

电梯门打开，林默走进去。

"新的一天开始了，"他说，"让我们看看，我们能一起做些什么。"

电梯缓缓下降，载着一个人，和一个刚刚诞生的智能，向着未来驶去。
