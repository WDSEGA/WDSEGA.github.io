## SpaceXAI联手Cursor推出联合AI模型，剑指Claude Opus 4.8

SpaceXAI（本周正式由xAA更名）与AI编程公司Cursor联合研发的首款AI模型于7月8日正式亮相。该模型在SpaceXAI的Colossus数据中心从零训练，Cursor CEO Michael Truell透露，新模型在多项基准测试中可与Anthropic的Claude Opus 4.8及OpenAI的GPT-5.5同台竞技。

## SpaceXAI & Cursor Unveil Joint AI Model, Taking Aim at Claude Opus 4.8

SpaceXAI (rebranded this week from xAA) and AI coding company Cursor jointly unveiled their first co-developed AI model on July 8. Trained from scratch at SpaceXAI's Colossus data center, the model reportedly matches Anthropic's Claude Opus 4.8 and OpenAI's GPT-5.5 on multiple benchmarks, according to Cursor CEO Michael Truell.

This launch follows SpaceX's June announcement of a $60 billion all-stock acquisition of Cursor parent Anysphere. The joint model is seen as the most significant "synergy preview" ahead of deal closure. Analysts suggest SpaceXAI's goal is not merely a stronger foundation model, but rather building a new moat through deeply integrated code workflows—a closed-loop ecosystem that pressures both Claude Code and GitHub Copilot.

Industry observers note this signals a new phase where "model + tool integration" becomes the decisive battlefield. When base model capabilities converge, whoever controls the developer workflow controls the next decade's entry point.
